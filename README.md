# 做图项目（zuotu）

这是一个专门用于和 ChatGPT 协作做图、保存提示词、参考素材说明和成图版本的 GitHub 项目。

## 目录结构

- `01_需求/`：每张图要表达什么、尺寸、用途、风格要求
- `02_参考素材/`：参考图说明、链接、素材备注
- `03_提示词/`：每次生成图片使用的提示词与修改记录
- `04_成图/`：最终采用的图片与版本说明
- `05_归档/`：旧版本、废弃方案、历史记录

## 工作方式

以后你只需要告诉 ChatGPT：

> 在 zuotu 项目里做一张……

我会先整理需求，再生成图片；需要保留到 GitHub 的文字资料、SVG、说明文件和版本记录会放入对应目录。

## 命名建议

每个绘图任务使用一个独立编号，例如：

`001_机器人概念图`

内部可以继续使用：

- `需求.md`
- `提示词_v1.md`
- `提示词_v2.md`
- `成图_v1.*`
- `成图_final.*`

这样以后即使做很多图，也能清楚追踪每一次修改。
